# ESTÉTICA — Landing page NOVAGENTE

Esta pasta contém a landing page interativa da solução **ESTÉTICA**, desenvolvida pela **NOVAGENTE**.

## Como visualizar

Abra o arquivo [index.html](./index.html) no navegador. É uma página autocontida: o HTML já inclui CSS, JavaScript, logo e imagens da apresentação.

## Publicação

Para hospedar em Cloudflare Pages ou outro serviço de sites estáticos, publique o arquivo `index.html` como página inicial do site. O endereço planejado é **estetica.novagente.com.br**, que depende da configuração de DNS e HTTPS.

## Escopo

Landing de apresentação comercial, com movimentos, interface demonstrativa e fluxos simulados. Não é o CRM/ERP de produção: WhatsApp real, autenticação e banco de dados não estão conectados.

## Organização

Esta versão foi isolada na branch `landing-estetica-novagente` do repositório público `salon-os`, sem alterar a branch `main`.
